# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 2.x | ✅ |
| 1.x | ❌ – update to 2.x (the 1.x app offers the update itself) |
| < 1.0 | ❌ |

## Reporting a Vulnerability

Don't report vulnerabilities in public Issues. Use **Security → Report a vulnerability** in
[SimonB50/librusek](https://github.com/SimonB50/librusek/security).

Include a description of the issue, steps to reproduce, the affected app version and, if known, a fix. This project follows a 90-day disclosure timeline.
